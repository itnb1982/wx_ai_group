四、平仓合理性审计

4.1 exit_reason 归因缺口（已修复）

全表 2342 笔平仓中，exit_reason 仅 859 笔记了 mt5_closed_external（外部/对账平仓），1483 笔为 NULL。AI 主动平仓的 tp/sl/保本/ai/反转/篮子锁利原因一个都没落库 → 无法从订单表归因平仓机制。

已修复：_record_close 现把 reason 归一化为枚举（l3_tp_lock / risk_cut / follower_mirror / breakeven / trailing / reverse / tp / sl / ai）写入 trades.exit_reason。

4.2 MFE / MAE 跟踪根因 bug（已修复）

全部 1712 笔已平交易 mfe / mae 恒为 0.0。深挖发现两处问题：

  • 隐藏根因：_track_mfe() 首调 prev = _EXIT_MFE.get(key, current_profit) 取默认=当前值，current_profit > prev 恒假 → 键从未写入 → 进程内 MFE 永远返回 0。M2 反思与 mfe_promote 进化日志（0 条从未触发）一直吃 0。这才是"MFE回灌空转"的真因。
  • 即使跟踪正确，trades.mfe/mae 列开仓写 0.0 后从未回写 DB（重启即丢、仪表盘 MFE 为假）。

已修复：① _track_mfe/_track_mae 改为首次必存值、正确累计最大浮盈/最大浮亏；② 新增 _track_mae 跟踪 MAE；③ _record_close 平仓时把 mfe/mae 回写 trades 表并消费内存键。
