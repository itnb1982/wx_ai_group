二、修复内容

后端修复

  1. debate_engine.py: HunyuanClient(api_key=hunyuan_key) 移除 secret_key 参数
  2. dashboard.py: 新增 /api/dashboard/decision POST 路由，真正调用 DebateEngine.decide()
  3. market_analyzer.py: 新增 _get_mock_snapshot()，MT5 未连接时返回随机模拟数据，AI 链路可独立测试
  4. accounts.py: 添加/重连后自动同步 balance/equity/profit/margin_level 到数据库
  5. auth.py: bcrypt → pbkdf2_sha256，解决版本不兼容
  6. trade.py: 新增 sl/tp 字段，数据库已重建
  7. mt5_service.py: 统一为明文密码接口，移除多余加解密

前端修复

  1. addKey(): 字段名改为 {provider, api_key, key_name, secret_key}
  2. saveStrategy(): 改为 PUT /api/strategy/{mt5_account_id}，字段名映射后端 schema
  3. refreshAIDecision(): 真正调用 /api/dashboard/decision，动态渲染双模型结果
  4. loadKeys(): 从 /api/keys/ 获取真实数据
  5. 金额格式化: 统一使用 fmt() 千分位函数，$992,725.16
  6. 自动刷新: MT5 账号页面加载后自动调用 sync，5 秒定时刷新

四、仍存在的问题 / 待办

#问题优先级说明
1MT5 全局单例限制🔴 高MetaTrader5 Python 库是全局单例，initialize() 会覆盖之前连接。当前多账号架构在同一进程内无法真正并行。短期方案：限制为单账号；长期方案：多 MT5 终端实例
2前端策略配置表单字段 ID 不匹配🟡 中前端有 riskPerTrade/maxDailyLoss 等字段，但 saveStrategy() 映射的是 max_position_lots/max_daily_loss_pct。需要统一表单 ID
3缺少交易执行定时任务🟡 中当前 /api/dashboard/decision 是手动触发，需要后台定时轮询
4交易日志未接入后端🟡 中前端 logs 数组是内存中的，未持久化到数据库
5WebSocket 未认证🟢 低/api/dashboard/ws 未做 JWT 认证，任何人可连接

五、下一步建议

按优先级逐个实现：

  1. 实现交易执行定时任务 — 后台每 N 分钟自动运行 AI 决策→风控→下单
  2. 修复策略配置表单 — 统一表单 ID 与后端字段名
  3. 接入真实 MT5 测试 — 添加 Demo 账号，验证下单/平仓链路
  4. 持久化交易日志 — 前端日志写入后端数据库
  5. WebSocket 认证
