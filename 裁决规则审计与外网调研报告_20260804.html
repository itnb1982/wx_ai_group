万象Ai · 裁决（MetaAgent）规则审计与外网调研报告

日期 2026-08-04 · 审计对象：主号 liumanchun1 实盘 186 笔 + adjudicate 源码 + 外网 ensemble/LLM-judge 最佳实践（≥3 源交叉验证）

核心结论裁决确实"乱来"，但病根是规则缺陷，不是"该不该上模型"

用户观察的两个现象——两模型结论相反仍开单、一方观望也开单——源码已确认是实打实的 Bug：adjudicate() 用 max() 取加权最高分，**没有共识门槛、没有分歧否决、没有 decision 字段规范化**。这导致"只要某个方向分最高就开"，哪怕两模型打架。

外网调研反而证明：不应让 LLM 当裁决（第三裁判）——LLM 有过度自信、性格偏差、确认偏误（≥3 源实证）；正确方向是优化现有规则聚合：共识不足=不交易（所有严肃 ensemble 系统的通用铁律）。

一、裁决规矩现在怎么定的源码逐行拆解（meta_agent.py:281-382）

流程：双模型初判 → 互相反驳（rebuttal）→ 按近期准确率取动态权重 → 加权融合 → max() 取最高分 → 输出 final_decision。

ds_conf = DS反驳后置信 ; hy_conf = HY反驳后置信
ds_w, hy_w = get_weights(体制)            # 近期准确率动态权重
decision_scores = {BUY:0, SELL:0, HOLD:0}
if ds_final=="BUY": scores[BUY]+=ds_conf*ds_w; active_w+=ds_w
elif ds_final=="SELL": scores[SELL]+=ds_conf*ds_w; active_w+=ds_w
# HOLD 沉默不投票
if hy_final=="BUY": scores[BUY]+=hy_conf*hy_w; active_w+=hy_w
elif hy_final=="SELL": scores[SELL]+=hy_conf*hy_w; active_w+=hy_w

# ★分歧惩罚太弱：
elif 一方BUY一方SELL: scores[HOLD]=(ds+hy加权)*0.3   # 只加 0.3 倍，BUY/SELL桶仍留分
final_decision = max(scores)                          # 直接取最高分 → 选了方向
final_conf = final==HOLD?...: final_conf/active_w     # 归一化后可能只有 0.3~0.4

三条致命缺陷（已对照源码确认）：

① 分歧硬开单：DS=BUY(0.6,w0.5)→BUY桶0.30；HY=SELL(0.6,w0.5)→SELL桶0.30；HOLD仅 (0.30+0.30)×0.3=0.18。max 取到 0.30 → 裁决以 BUY 或 SELL 开单，终裁置信仅 0.30。截图里"置信40%"正是这种归一化产物。

② 单模型开单：DS=BUY、HY=HOLD（观望）→ active_w=0.5，裁决直接以 BUY 开单（归一化后）。你看到的"一方观望也开单"多属此类。

③ 缺 decision 规范化：_safe_json_loads 不规范化 decision，LLM 若返回 "buy" 小写或 "观望" 中文，== "BUY" 判断全部失效，会静默错判。

来源核心结论对本案的启示

AI Consensus Trading		"only acting when they agree"——只在模型一致时才交易；分歧时系统"自然变得更谨慎，在不确定性最高时减少暴露"分歧=减仓信号，不是开仓信号

Conviction-Weighted		分层：STRONG(3+策略+60%置信)立即；BUY/SELL(2+策略+50%)谨慎；WEAK(多数但弱)几乎不执行弱共识降级而非硬开

For-Loop Consensus		用 超多数≥70% 而非简单多数，过滤"分裂投票"，否则灰色（中性/不交易）分裂=不参与

问题B：要不要让 LLM 当裁决（第三裁判）？ 调研一致否定

来源LLM 当金融裁决的硬伤
marketmatrix
实盘竞赛实测		AI 自带"交易性格偏差"：Claude 偏单边做多、Gemini 无做空顾虑、通义敢重仓加杠杆；同一指令不同 AI 决策截然不同
themoonlight
论文评述		①目标偏差：LLM 优化"似然+人类偏好对齐"，与风控目标根本不匹配 ②过度自信：被训练成"自信获高奖励、表达无知受罚"→ 会以高置信度猜测、隐藏无知 ③CoT 是事后合理化
alphaxiv
偏见研究		LLM 有固有偏见→确认偏误，面对反证也顽固坚持初始判断
ownyourai
偏差实证		外推陷阱（追涨杀跌）、过度乐观（预测收益≈实际2倍）、尾部风险误判

结论：让 LLM 当"终裁法官"，等于把系统命运交给一个会盲目自信+有性格偏差+确认偏误的裁判，还增加延迟/成本/不可解释性。你已有 DS+HY 双 LLM 辩论，再加第三个 LLM 只是叠加同样的毛病。正确做法=优化规则聚合（共识门槛+分歧否决）。

三、裁决规则优化方案（提准，不砍盈利单）待你确认后落地

原则：沿用"AI 出意图、规则守底线"双轨；共识强才开、分歧/弱共识不交易；保持可解释、可回测、可控。

R1
分歧强制 HOLD：DS/HY 一方 BUY 一方 SELL → 终裁直接 HOLD，不开单
R2
单模型方向+另一 HOLD → 允许开但门槛提高至 0.70（仅一个模型支持=谨慎）
R3
双 HOLD → 强制 HOLD，加规范化保障 + 日志明示"双观望不交易"
R4
decision 规范化：upper() + 中文/同义词映射（观望/hold→HOLD，做多→BUY 等）

具体裁决新逻辑（伪码）：

if ds_final==HY_final=="HOLD":           # 双观望
    return HOLD
if ds_final!=HY_final and 二者都有方向:     # 分歧（BUY vs SELL）
    return HOLD                            # ★R1 不再硬选方向
if 一方方向 + 另一方HOLD:                   # 单模型
    门槛 = 0.70                            # ★R2 提高
else:  # 同向共识
    门槛 = 0.65                            # ★强共识可略低
final = 同向方向 if 归一化置信>=门槛 else HOLD
# 极端风险 / 风控护栏 一票否决（不变）

与之前审计的联动：本方案配合上一轮建议的"开仓门槛 0.5→0.65、反转平仓 0.6→0.75"形成完整提准链。但本次只动裁决聚合规则，不与持仓/出场改动混在一起，便于你逐个验收。
