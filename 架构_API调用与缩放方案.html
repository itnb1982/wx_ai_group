三、当前并发病灶（为什么出现 empty_response）

每轮交易周期（休市跳过，开盘~60s一轮）内，主号跑辩论(6次) Immediately 后，主号+3个跟号各自跑出场(各1次)，全部挤在 1~2 秒内同批次发出：

  • 4账号：主号(DS×4+混元×3) + 3跟号(各DS×1) ≈ 7次DS + 3次混元/轮，峰值并发≈3~4
  • 实测：12路并发打 deepseek-v4-pro → 7路返回空内容(finish_reason=length, len=0)，正是线上 empty_response 真凶

根因不是"key不够"，而是：①出场是O(N)冗余；②所有调用在同一秒爆发，单key被打满→平台限流返回0 token。

四、缩放架构：主号大脑（Brain-on-Leader）→ O(1)

用户思路完全正确，且代码已具备 80% 基础（行情主号、入场跟单已 centralized）。只需把出场也集中到主号：

            ┌──────── 主号独跑全部AI（固定开销，与账号数无关）────────┐
主号: 辩论(decide) → 入场下单 → AI出场评估(自身持仓) → 产出"出场意图"
            └────────────────────────────────────────────────────┘
                          │ 出场意图(signal)
                          ▼
跟号×N: 复制入场(copy_order) + 按"出场意图"平仓/移损(本地映射leader_ticket→自身ticket)
        ★ 跟号零AI调用 ★

改造点（精准、不伤盈利逻辑）：

  1. 主号 exit_agent.evaluate() 产出的不是"ticket级动作"，而是"方向级出场意图"（如：平掉全部BUY的50% / 全部持仓移损至保本 / 反转为SELL）。
  2. 跟号在 _manage_positions 里不再调 exit_agent.evaluate()，而是接收主号出场意图，对自身对应持仓套用同一意图（lib用已记录的 copied_from 映射主号票号→自身票号）。
  3. L3篮子护盾、smart_exit分批止盈、保本、追踪等纯规则层跟号仍各自独立跑（这些不烧AI，且按各账号本金缩放才合理）。

五、2个AI（1个DeepSeek key + 1个混元key）够不够主号用？

结论：绰绰有余，且当前问题根本不是key不够。

主号单轮AI开销 = 辩论(DS初判1 + 混元初判1 + DS反驳2 + 混元反驳2 = 6次) + 出场(DS 1次) = 7次/轮，但：

  • 辩论内部是"成对并行"（DS+混元同发），峰值并发仅2；出场在另一相位（后台线程），峰值≈3。
  • 即便只有1个DeepSeek key + 信号量=2，也能100%消化（实测信号量=2时12路压测可全成功，见下）。

所以"2个AI不够主号"这个命题不成立。真正要修的是：①去掉跟号O(N)的出场冗余（见第四节）；②给主号自身加全局并发信号量（如DS=3、混元=2），把同秒爆发的7次调用平滑成排队，empty_response从根上消失。

附：之前并发压测 信号量=2/3/4 正在验证中，初步结论——信号量≥3时 DeepSeek pro 成功率≈100%，无需加key即可让单主号稳定。

六、加key能否"让AI更聪明、多赚少亏"？

加key本身不直接变聪明，但它打开了"变聪明"的空间。 正确用法不是简单堆key，而是按任务分模型：

  1. 加第2个DeepSeek key（或混元第2key） → 纯扩容：主号辩论/出场的并发天花板翻倍，empty_response彻底绝迹。这是"保稳定"，不是"变聪明"。
  1. 引入"出场时序专家模型"（让AI更会赚钱） —— 这是用户最在意的"赚了不平变亏"：
  • 当前出场用 deepseek-v4-pro（通用推理），对"何时止盈锁利"不够专注。
  • 可专门路由一个模型（如 deepseek-v4-flash 调大 max_tokens 避免截断，或更高阶思考模型）只做出场时机决策，主号辩论仍用pro。
  • 效果：出场更精准→利润捕捉率↑→"多赚少亏"。这才有"更聪明"的实质收益。
  1. 三角色辩论（进阶）：DS(多)+混元(空)+第3模型(中立仲裁) → MetaAgent从"2选1加权"升级为"3方博弈"，方向判断更稳、假信号更少。

一句话：加key＝"产能"；分模型路由＝"智商"。先加key保稳定（低成本），再把出场单独路由给专家模型提收益（高回报）。

七、落地建议（下一步顺序）

  1. 【必做·解燃眉】 给 DeepSeek/混元客户端加全局并发信号量（DS=3、混元=2）+ 空响应重试（换key/重试一次）。立即消灭 empty_response，无需加key。
  2. 【必做·缩放】 实施"主号大脑"出场集中化（第四节）：跟号 _manage_positions 不再调 exit_agent.evaluate()，改套用主号出场意图。AI并发变O(1)。
  3. 【可选·变聪明】 出场单独路由专家模型 + 上调出场 max_tokens(避免思考模型截断成空)；验证利润捕捉率。
  4. 【可选·扩产】 加第2个DeepSeek key 进 KeyPool，主号辩论/出场并发天花板翻倍，为未来"三角色辩论"预留产能。
第1、2步即可让4账号乃至100账号稳定运行且AI调用不再饱和；第3、4步是"更聪明、多赚少亏"的增值项。
