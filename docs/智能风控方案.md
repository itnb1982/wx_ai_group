### 1.3 取舍结论

- **手数方法**：选 **PMTS 波动率反比 + AlphaMind 信号调制 + PredictEngine 同向衰减** 三合一 → 形成我们的 `vol×sig×dir` 公式
- **分批止盈**：直接采用 **AlgoMatrix 4-TP** 方案（实战经验值，GitHub DRL 项目 zero-was-here 也在用类似方案）
- **追踪止损**：选 **Pro-Scalper 1.5×ATR**（黄金特性优化过）
- **不做 Full Kelly**：用 fractional（25% Kelly ≈ 1.0% 风险/笔），永不超 5% 风险/笔

## 2. 设计方案

### 2.1 智能手数公式

```
base_risk$   = balance × max_risk_per_trade_pct / 100
base_lots    = base_risk$ / (ATR × 100)            # 黄金 1手 1点 = $100
raw_lots     = base_lots × vol_mult × sig_mult × dir_mult
final_lots   = clamp(raw_lots, [min_lot, max_lot], max_position_lots)
```

| 系数 | 默认 | 范围 | 含义 | 出处 |
|------|------|------|------|------|
| `vol_mult` = `volatility_factor` | 1.0 | [0.3, 2.0] | 强趋势加码（>1）/ 弱趋势缩手（<1） | PMTS 波动率反比 |
| `sig_mult` = `0.6 + 0.4 × conf` | 0.6~1.0 | [0.6, 1.0] | AI 信号强度调制 | AlphaMind |
| `dir_mult` = `(1-decay)^N` | 1.0→0.5→0.25 | [0.1, 1.0] | 同向第 N 单衰减 | PredictEngine portfolio heat |
| `sizing_mode` = 'fixed' | 退化为旧逻辑 | 兼容 | 旧账户不破坏 | 防御性兼容 |

**举例**：$5,000 账户，ATR=20，conf=0.85，无同向持仓
- `base_risk$` = 5000 × 0.02 = $100
- `base_lots` = 100 / (20×100) = 0.05 手
- `raw_lots` = 0.05 × 1.0 × 0.94 × 1.0 = 0.047 → clamp 到 0.05

**举例**：$1,000 账户，ATR=10（低波动），conf=0.9，vol_factor=1.3
- `base_risk$` = 1000 × 0.02 = $20
- `base_lots` = 20 / (10×100) = 0.02 手
- `raw_lots` = 0.02 × 1.3 × 0.96 × 1.0 = 0.025 手 ✓

### 2.2 智能分批止盈（5 道防线）

| 防线 | 触发条件 | 动作 |
|------|---------|------|
| ⑤ AI 反向 + 置信度 | 反向决策 + conf ≥ `ai_reverse_close_confidence` | **立即全平** |
| ④ 追踪止损被扫 | SL 已被追踪到价外 | 平台自动平仓 |
| ③ TP2 激活追踪 | 价格距入场 ≥ 0.8 × tp2 × ATR | 把 SL 移到 `current - trail×ATR`（只往有利方向移） |
| ② TP1 触发保本 | 价格距入场 ≥ tp1 × ATR | 平 40% + SL→入场+buffer |
| ① 4 级分批 | TP1/TP2/TP3 各档 | 按比例平仓 40% / 30% / 20% / 10% |

**默认 4 级**：
- TP1: 1.0×ATR 平 **40%** + 保本单
- TP2: 1.5×ATR 平 **30%** + 激活追踪
- TP3: 2.5×ATR 平 **20%**
- TP4: 剩余 **10%** 留 runner（追踪止损捕获）

### 2.3 追踪止损规则

```python
trail_distance = ATR × trailing_atr_mult   # 默认 1.5×ATR
if BUY:  new_sl = current_price - trail_distance
if SELL: new_sl = current_price + trail_distance
新 SL 只往有利方向移动（BUY 只能上调，SELL 只能下调）
```

### 2.4 每账号独立配置（21 个新字段）

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `base_capital` | float | 1000 | 该账号基础本金 $（手数自适应基准） |
| `sizing_mode` | str | "smart" | smart 智能 / fixed 固定 |
| `volatility_factor` | float | 1.0 | 趋势强度系数（0.3~2.0） |
| `same_direction_decay` | float | 0.5 | 同向第 N 单 × (1-此值)^N |
| `min_lot_per_trade` | float | 0.01 | 单笔最小手数 |
| `max_lot_per_trade` | float | 1.0 | 单笔最大手数 |
| `max_concurrent_same_direction` | int | 3 | 同向最多并发 |
| `smart_tp_enabled` | bool | True | 启用智能分批 |
| `tp1_atr_mult` | float | 1.0 | TP1 距入场 1.0×ATR |
| `tp1_close_pct` | float | 0.40 | TP1 平 40% |
| `tp2_atr_mult` | float | 1.5 | TP2 距入场 1.5×ATR |
| `tp2_close_pct` | float | 0.30 | TP2 平 30% |
| `tp3_atr_mult` | float | 2.5 | TP3 距入场 2.5×ATR |
| `tp3_close_pct` | float | 0.20 | TP3 平 20% |
| `breakeven_after_tp1` | bool | True | TP1 后保本 |

## 4. 验证标准（用户铁律）

> "唯一目标：多交易、多赚钱"（不是纸面漂亮指标）

| 检查项 | 标准 | 失败动作 |
|--------|------|---------|
| ① 交易笔数 | 不下降 | 回退 |
| ② 净利润 | 不下降 | 回退 |
| ③ PF | > 1 | 回退 |
| ④ 用户体验 | 每账号独立可视化 | 改进 UI |

**回退策略**：所有新参数都有默认（智能=原始行为），客户手动切到 `sizing_mode='fixed'` + `smart_tp_enabled=False` 即可 100% 退回旧版。
