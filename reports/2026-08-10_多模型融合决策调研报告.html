三、全球调研结论综述

3.1 学术界/工业界对多模型融合交易的共识

  • 没有单一模型在所有 regime 下都最好。论文 Adaptive Market Intelligence: A MoE Framework for Volatility-Sensitive Stock Forecasting（2025）指出，MoE 框架在高波动/低波动 regime 下分别比单一模型提升 MSE 33%/28%。
  • 时序基础模型（TSFM）在金融数据上优势有限且需谨慎评估。Noguer i Alonso & Pereira Franklin（2026）对 TimeGPT、TimesFM-2.5、Moirai-2.0、Chronos、Chronos-2 的评测发现：虽然 TSFM 在排名分布上占优，但相对随机游走的收益“很小且稀疏”，只有 Chronos（AMZN）和 Moirai（GOOG）在 Diebold-Mariano 检验中显著优于随机游走。
  • 预训练是起点，金融微调才是关键。PapersWithBacktest 指出，通用预训练模型在金融 zero-shot 上往往表现一般，必须在特定资产/频率上做 few-shot fine-tuning 才可能有实际收益。
  • 概率校准比点预测更重要。ICLR 2026 论文 Beyond Accuracy: Are TSFMs Well-Calibrated? 指出，现有指标（CRPS/WQL/MSIS）会混淆校准与锐度，应使用专门校准指标评估不确定性估计是否可信。
  • LLM 适合作为“解释/审计/元学习器”，而非直接方向票。TradExpert（2025）用四个专门 LLM 处理新闻/市场/因子/基本面，再由通用 LLM 综合；MoE-F（ICLR 2025）用在线过滤门控动态加权多个 LLM/专家，在金融市场运动任务上比最佳单一 LLM 提升 F1 17%/48.5%。

3.2 关键文献要点

来源核心结论

4.2 设计合理性分析

方案 A：把四个模型作为“第四/五/六票”直接加入加权投票

  • 优点：简单，复用现有 Meta-Agent 加权框架。
  • 风险：TimesFM/Time-MoE/Moirai 目前只做 zero-shot，未针对 XAUUSD H1 微调；其置信度（如 Moirai 1.00）可能过自信；直接加权可能引入噪声，甚至压低盈利交易笔数。

方案 B：由 Qwen3-8B 做“参考模型结果审计员/融合员”

  • 优点：符合 Qwen 当前 L0 校对员角色定位；让 8B 模型做“元决策”而非直接方向投票，避免违反“8B 模型金融方向判断近随机”的铁律。
  • 风险：Qwen 的推理延迟约 21s（p50），若放在交易热路径会拖慢循环；更适合离线/辅助审计，而非实时方向门。

方案 C：由 DeepSeek + 混元读取四个模型结果后再做方向判断

  • 优点：云模型能力更强，提示中可包含本地时序预测作为附加证据；与现有辩论流程自然结合。
  • 风险：会增加 token 消耗和延迟；且云模型对数值时间序列的推理能力有限，可能“看懂文字但算错数字”。

方案 D：在线门控 / 动态权重（MoE-F 思路）

  • 优点：不固定权重，根据每个模型近期表现动态调整，学术界已证明在金融任务上有效。
  • 风险：实现复杂，需要持续跟踪每个模型在最近 N 次预测中的命中率，才能估计“运行表现”。

六、调研结论与建议

6.1 核心结论

“把四个参考模型实时喂给 Qwen + DeepSeek + 混元做方向门”在技术上是可行的，但在当前状态下贸然接入交易决策链风险高于收益。

  • 学术界支持“多模型融合 + 动态门控”能提升预测稳健性，但前提是模型经过资产特定微调、概率校准良好、且融合方式经过 walk-forward 验证。
  • 当前 TimesFM/Time-MoE/Moirai 均为 zero-shot 参考模型，未针对 XAUUSD H1 微调，Moirai 的 1.00 置信度更可能是过自信而非高胜率信号。
  • Qwen3-8B 当前角色应为“校对员/元审计员”，不宜直接作为实时方向门；DeepSeek/混元可读取参考模型结果，但会增加延迟与成本。

6.2 分阶段落地建议

阶段动作预期产出
Phase 0
（建议立即做）		在参考面板继续观察 4 个模型，记录它们对未来 N 根 K 线（如 4 根 H1）的方向命中率；不接入交易。获得各模型在 XAUUSD H1 上的真实命中率、置信校准曲线。
Phase 1
（1-2 周后）		如果某参考模型命中率显著高于随机（如 >55% 且持续），以“低权重附加票”形式接入 Meta-Agent，权重不超过 0.10，且仅在它与云双脑同向时增强 confidence。验证是否提升净利润而不腰斩交易笔数。
Phase 2
（命中率稳定后）		引入 MoE-F / 动态权重机制：根据近期表现自动调整各参考模型权重；由 DeepSeek/混元在提示中读取参考模型摘要作为辅助证据。实现自适应融合，降低单一模型失效影响。
Phase 3
（可选）		在本地 GPU 资源允许且经过 fine-tune 后，将表现最好的 1-2 个 TSFM 作为正式投票成员；Moirai 因依赖 py312 venv、包冲突复杂，建议最后考虑。形成“云双脑 + 1-2 个微调本地时序模型”的稳定组合。

6.3 与既有铁律的对照

  • 多交易多赚钱：接入新模型必须以“不减少交易笔数、不降低净利润”为及格线；任何方向门若导致过滤增多，即违反用户铁律。
  • 提准非拦截：应通过提高信号方向准确率来增加盈利，而不是砍掉能赚钱的入场。动态权重/门控的设计要偏向“增强同向信号”，而非“拦截反向信号”。
  • 8B 模型不做等权方向投票：Qwen 可以做参考模型结果摘要/审计，但不能与 DeepSeek/混元/Chronos 并列投票。
  • 参考模块解耦红线：若接入，必须由交易决策链主动拉取参考模块输出，不能让参考模块反向 import 交易模块。

6.4 最终建议

建议采纳“观察先行、低权重后入、动态权重”的分阶段方案；不建议明天就直接把四个模型接入方向门。

先用 1-2 周收集四个模型在真实行情中的命中率数据，再选择其中 1-2 个表现最好的以低权重接入，并严格按“净利润↑ + 交易笔数不腰斩”验收。DeepSeek/混元可以在提示中读取参考模型摘要作为辅助证据，但 Qwen 应保持校对员角色，不做实时方向门。
