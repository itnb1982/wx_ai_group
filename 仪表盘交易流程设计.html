万象AI — 仪表盘「AI 交易大脑」设计 v2（去平庸版）

2026-08-02 v2 | 修订说明：v1 平庸的根因是"在讲管道、不在讲产品"。本版把所有地基性内容压成前提，聚焦 6 个招牌亮点——这些是别人没有、且直接服务"多赚钱 / 提准确率 / 不拦截"铁律的差异化体验。

0. 一句话定位（The Hook）

万象AI 不是一个看盘面板，而是一个"能吵架、能认错、能进化"的 AI 交易大脑。<br>4 个账号不是 4 个机器人，而是一个有主见的资本分配引擎：它让两个 AI 模型当场辩论、用"共识度"当风控开关、把每一美元利润追溯到某次 AI 决策、并随每一笔交易自我进化。

1. 平庸版 vs 万象AI（直面对比）

维度市面平庸交易 bot万象AI v2
决策过程黑盒：输入行情 → 输出买卖白盒：双模型当场辩论，推理过程全程可见
不确定性处理假装永远正确，给个方向就干共识度仪表：两模型分歧越大越克制，分歧即风控
多账号复制同一信号到所有账号资金分配矩阵：按置信度+各账号战绩动态调配，强信号全火力、弱信号只让最猛的账号小仓试
外部数据只有价格四维体温计：黄金×美元指数×恐慌指数×波动率交叉验证
效果验证"回测很美"（谁信）盈利归因：AI 置信度>0.8 时胜率多少、赚多少，实时公示
系统成长上线即定型自进化闭环：每平仓一笔就复盘 AI 对错，动态调整两模型权重

结论：平庸版卖的是"功能清单"，万象AI 卖的是"一个活的、可信的、会进化的交易大脑"。

2. 六大招牌亮点

标注：✅ 已落地地基 / 🟡 已具备接口待接 UI / 🔧 需新建

亮点一：AI 辩论擂台（实时可视化）🟡

是什么：仪表盘上不是一个冷冰冰的"买/卖"按钮，而是一场看得见的辩论直播——DeepSeek V4（激进派）与混元 Hy3（稳健派）就"现在该不该做多黄金"当场互驳，Meta-Agent 当裁判。

为什么是亮点：

  • 市面上 99% 的 EA / 跟单系统是黑盒，用户永远不知道"为什么开这单"。万象AI 把推理过程摊开，这是信任的源头——你愿意把钱交给一个敢把思考过程给你看的大脑。
  • 辩论不是噱头：debate_engine.py 已是 2 轮交叉辩论 + 提前共识终止的真实逻辑，我们只是把已发生的辩论转录搬上大屏。

怎么落地（依托现有 debate_engine.decide()）：

decide() 当前返回 DebateDecision（最终方向+置信度）
↓
新增：decide_verbose() 返回完整辩论转录：
  {
    "round1": {"deepseek": {...论据}, "hunyuan": {...论据}},
    "round2": {"deepseek_rebuttal": ..., "hunyuan_rebuttal": ...},
    "meta_verdict": {...},
    "transcript": "可渲染的对话流"
  }
↓
WebSocket 推送 → 前端「辩论擂台」组件逐句渲染两模型发言

界面长啥样：左右两栏气泡对话（左 DeepSeek 红方/右 混元 蓝方），顶部 Meta-Agent 裁决条，底部"共识度"进度条。用户甚至能点开任意一轮看双方怎么互怼。

亮点二：共识度仪表 — 分歧即风控 🟡

是什么：把"两个模型有多一致"做成仪表盘上最重要的一个数字（0%~100%），它同时是风控开关。

为什么是亮点（直击你的铁律）：

  • 你的哲学是"提准确率、不拦截"。传统做法是用过滤器砍信号（腰斩交易数），而我们用共识度这个连续量来"提准"——两模型高度一致才全仓，分歧大就降仓，一笔都不省，只是把钱押在更可能对的地方。
  • 实证：XAUUSD 与 DXY 负相关 -0.85，当两模型+外部数据三者对齐时胜率 74%；全部中性时仅 39%（≈扔硬币）。分歧本身就是最有价值的信号，平庸系统却把它藏起来了。

怎么落地（依托 MetaAgent.adjudicate() 已输出的 confidence + deepseek_weight/hunyuan_weight）：

共识度 = 1 - |DS_vote - HY_vote| 调整权重差
  ├─ 共识度 > 80%  → 强信号：全账号满仓风险预算
  ├─ 共识度 50~80% → 中信号：仅 Top2 战绩账号
  ├─ 共识度 < 50%  → 弱信号：仅最佳账号 1/3 仓，或 HOLD
  └─ 两模型反向（一多一空）→ 强制 HOLD + 弹出"分歧告警"

界面长啥样：环形仪表盘，绿区（高共识）= 放手干，红区（分歧）= 克制。旁边一行小字："当前共识度 87% — 双方一致看多"。

亮点三：四维市场体温计（Gold × DXY × VIX × 波动率）✅

是什么：不只看黄金价格，而是用四个独立维度交叉给黄金"测温"——金价本身、美元指数 DXY、恐慌指数 VIX、以及 XAUUSD 自身波动率。当四者指向同一方向，才是真正的高置信信号。

为什么是亮点：

  • market_data.py 已落地 DXY（yfinance）、VIX（yfinance）、XAU-DXY 滚动相关性（-0.85 实证）。这是别人要额外付费（Bloomberg）才能有的视角，我们零成本免费拿。
  • 平庸系统只在黄金自己的 K 线里打转；万象AI 用"美元涨→黄金跌"这个宏观镜像做交叉验证，把单一品种的方向判断升维成宏观共振判断。

怎么落地：

四维输入：
  ① 金价技术面（RSI/MACD/布林/ATR/趋势，已落地）
  ② DXY 美元指数 + 日涨跌（已落地 yfinance）
  ③ VIX 恐慌指数 + 分区 low_fear/normal/fear/extreme（已落地）
  ④ XAUUSD 波动率 regime（正常/高波/极端，已落地）

合成「市场体温」：
  黄金方向信号 × (DXY 反向确认) × (VIX 避险加成)
  → 四轴共振 = "体温正常且方向明确" = 最强信号
  → 四轴打架 = "体温紊乱" = 系统自动降仓（呼应亮点二）

界面长啥样：四个并列的"体温计"卡片（金/美元/恐慌/波动），每个显示当前读数和分区颜色，底部一个"共振度"综合灯（绿/黄/红）。

亮点四：资金分配矩阵 — 置信度驱动的多账号博弈 🔧

是什么：4 个账号不再复制同一笔单，而是变成一个按置信度 + 各账号实时战绩动态调配的资本分配引擎。

为什么是亮点（这是 v1 最蠢的地方，必须改）：

  • v1 设计是"AI 决策广播到所有开启交易的账号"——这等于把同一注筹码押 4 次，是笨钱，没有任何智能。
  • 万象AI 的逻辑：强信号时 4 个账号全火力铺开吃满利润；弱信号时只让战绩最好的那个账号小仓试水；当某账号出现反向信号，甚至允许它做小对冲让组合净敞口中性。4 个账号从"4 个克隆体"变成"1 个组合优化器"。

怎么落地（依托现有多进程 Worker + Trade 表）：

每个账号实时战绩 track_record（从 DB Trade 表聚合）：
  { win_rate, profit_factor, current_drawdown, recent_pnl }

Meta-Agent 输出：{ direction, confidence, conviction: weak/medium/strong }

分配引擎 allocation_engine.allocate(decision, track_records):
  strong + 共识度>80% → 全部 4 账号，各自满风险预算
  medium             → Top2 战绩账号，满预算
  weak               → 仅最佳账号，1/3 预算
  反向信号出现在某账号 → 该账号开小对冲单（组合净敞口≈0）

界面长啥样：一张「分配矩阵」表格——行是 4 个账号，列是"战绩/本次分配仓位/本次方向"。用户一眼看到"这次强信号，4 个账号全部出击，预计总风险 $X"。

亮点五：盈利归因 — 每一美元追溯到 AI 决策 🔧

是什么：仪表盘上公示一个让所有跟单系统汗颜的数字——"AI 置信度越高，实际胜率/盈利越高"的实测曲线。把每一笔利润的功劳（或锅）明确算到某次 AI 决策头上。

为什么是亮点：

  • 直接回应你的铁律"多赚钱、PF>1，不是纸面漂亮指标"。归因不是漂亮指标，是证明 AI 真的在帮你赚钱的证据。
  • 当公示出"AI 置信度>0.8 时，过去 30 天胜率 76%、平均盈利 $X；置信度<0.5 时胜率 41%、平均亏损 $Y"，用户就 知道该信 AI 到什么程度——这反过来让亮点二的"共识度风控"有了数据支撑。

怎么落地（Trade 表已存 AI 决策详情，扩展字段即可）：

Trade 表新增：
  ai_confidence     — 下单时 Meta-Agent 置信度
  ai_consensus      — 当时两模型共识度
  ai_direction      — AI 判的方向
  debate_summary    — 辩论结论摘要

平仓后自动评分：
  ai_correct = (ai_direction == 实际盈利方向) and (profit > 0)
  → 聚合："置信度分桶胜率表" + "共识度分桶胜率表"
  → 仪表盘「AI 成绩单」：分桶柱状图

界面长啥样：一张「AI 成绩单」柱状图，X 轴是置信度分桶（<0.5 / 0.5-0.8 / >0.8），Y 轴是对应桶的胜率与平均盈亏。一条绿线越往右上走，说明 AI 越自信越准——这就是系统价值的铁证。

亮点六：自进化闭环 — 交易即训练 🔧

是什么：系统每平一笔仓就复盘一次 AI 的推理对不对，并据此动态调整两个模型的权重，让大脑随交易越用越聪明。

为什么是亮点：

  • 平庸系统"上线即定型"，参数写死。万象AI 把每一次交易变成一次训练样本——DeepSeek 这次在突破行情上又错了？自动下调它在突破类场景的权重；混元在震荡市更稳？上调。
  • 叙事价值："你的 AI 不是雇来的，是养大的。" 这对用户是极强的长期黏性。

怎么落地（依托 debate_engine 已有权重 + 亮点五的评分）：

每笔平仓 → 评分 ai_correct + 场景标签（突破/震荡/趋势/避险）
→ 更新模型权重表 model_weights：
    breakthrough_scenario: { deepseek: 0.35, hunyuan: 0.65 }  ← 震荡派占优
→ MetaAgent 下次 adjudicate 时按场景取权重
→ 仪表盘「进化日志」：显示权重随时间的迁移

界面长啥样：一条「AI 进化时间线」，展示"某日因突破行情连续误判，DeepSeek 在突破场景权重从 0.5 降到 0.35"。让用户看见系统在成长。

3. 核心数据流（带亮点标注）

每 N 秒/分钟一个决策周期
│
├─ Step 0  行情采集（主号 Worker）
│   主号 mt5_service → get_market_data("XAUUSD") → 5 框架 OHLCV
│   + market_data_provider → DXY / VIX / 相关性
│   → 🟢【亮点三 四维体温计】合成市场体温
│
├─ Step 1  双模型辩论（debate_engine）
│   DeepSeek V4 ↔ 混元 Hy3，2 轮交叉辩论
│   → 🟡【亮点一 辩论擂台】转录全程可见
│
├─ Step 2  Meta-Agent 加权裁决
│   输出 {direction, confidence, consensus, conviction}
│   → 🟡【亮点二 共识度】分歧即风控
│
├─ Step 3  资金分配矩阵（allocation_engine）🔧
│   按 conviction + 各账号 track_record 决定谁交易、多大仓
│   → 🔧【亮点四 多账号博弈】
│
├─ Step 4  风控审核 + 各账号独立下单（各自 Worker）
│   不拦截、不减笔数，只调仓控风险（提准非拦截）
│
├─ Step 5  记录 Trade（含 ai_confidence / consensus / debate_summary）🔧
│   → 🔧【亮点五 盈利归因】数据源
│
├─ Step 6  平仓后评分 → 更新 model_weights → 进化日志🔧
│   → 🔧【亮点六 自进化】
│
└─ Step 7  WebSocket 推送仪表盘（辩论擂台 / 体温计 / 分配矩阵 / 成绩单）

5. 实施路线（MVP 先行，避免又陷平庸）

阶段内容依赖标注
MVP-A辩论擂台 UI（接入 decide_verbose 转录）改 debate_engine + dashboard.py + 前端🟡 1~2 天
