# ============================================================
#  本地时序模型（重型可选依赖）
# ------------------------------------------------------------
#  为什么单独成文件：
#    torch(CUDA) 解包后约 2.5~3GB，下载耗时长。核心交易链路
#    （行情/风控/下单/云端双脑）**不依赖**本文件即可运行；
#    缺失时 Chronos 自动降级为 SMC/Regime + NumPy 方向终审，
#    系统照常交易，只是少了本地时序增强。
#
#  安装（在项目根目录，原生 cmd / PowerShell 下执行）：
#    .venv\Scripts\python.exe -m pip install -r backend\requirements-ml.txt
#
#  ★★ 致命陷阱（2026-08-08 实测，务必写进部署手册）★★
#    在 Git Bash / MSYS2 / Cygwin 终端里 `import torch` 会触发
#    0xC0000005 ACCESS_VIOLATION 段错误（exit 139 / 3221225477），
#    而同一个解释器在原生 cmd / PowerShell 下完全正常。
#    → 因此**必须用 start_all.bat（原生 cmd）或 PowerShell 启动后端**。
#    → 若用 Git Bash 启动，Chronos 探针会误判"永久降级"并写盘缓存，
#      导致本地时序模型再也不加载。此时需删除
#      backend/data/torch_probe_cache.json 后用原生终端重启。
# ============================================================
