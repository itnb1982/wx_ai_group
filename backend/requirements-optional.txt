#
# ⚠️ 极其重要 —— torch 与 Python 版本必须严格匹配：
#    torch 的 _C.cpXXX-win_amd64.pyd 是按具体 Python 小版本编译的二进制。
#    如果你把 .venv 建好之后又升级了底层 Python（哪怕只是 3.13.12 -> 3.13.14），
#    import torch 会触发【原生 access violation / 0xC0000005】，
#    这个崩溃是 Python 层 try/except 抓不住的，会让整个进程瞬间消失。
#    本系统已用「子进程探针隔离」防住了这个坑（见 chronos_service.py），
#    崩溃只会导致自动降级、不会拖垮服务。但若要真正启用 Chronos，
#    请在升级 Python 后重建 .venv 并重新安装 torch。
# ============================================================
