四、根因定位（代码 + 配置铁证）

配置 app/config.py:164

SMC_FLOW_GUARD: str = "hard" # 逆机构订单流直接翻向 SMC_FLOW_FLIP_CONF: float = 0.66 # 翻向置信门槛

代码 app/core/meta_agent.py SMC 订单流锚（HARD）分支：

elif _smc_guard == "hard": _flip_to = "BUY" if _smc_bias == "bullish" else "SELL" ... elif final_confidence >= 0.75: # 仅高置信共识受保护 final_confidence *= 0.85 # 不翻向 else: final_decision = _flip_to # ← 0.66~0.75 的中等共识在此被翻向！

翻向发生的唯一通道：SMC_FLOW_GUARD=hard + smc_features.global_bias=="bullish" + final_confidence < 0.75 且非极端位。 代码注释（L1087-1090）自己已承认「单 SMC 子信号不得否决高置信多模型共识」，但仅用 0.75 做保护—— 0.66~0.75 的中等共识仍被翻向。实证中三脑 SELL 共识置信恰落此区间，被 smc=bullish 全部翻成 BUY。

五、已落地修复（共识闸门）

原则：只要三脑（DS/HY/Chronos）已有方向共识，单 SMC 子信号只能降权、绝不翻向；仅当三脑无共识时才允许翻向（保留 Fix A「顺机构订单流」原意）。

# 计算三脑方向共识（≥2/3 或 2/2 多数） _brain_votes = [v for v in (ds_final, hy_final, chronos_dir) if v in ("BUY","SELL")] _brain_cons = 多数方向 if 存在 else None elif _smc_guard == "hard": if _brain_cons is not None: # ★ 新增闸门 final_confidence *= 0.85 # 仅降权，绝不翻向 elif final_confidence >= 0.75: final_confidence *= 0.85 elif _at_extreme: final_decision = "HOLD" else: final_decision = _flip_to # 仅无共识时翻向
