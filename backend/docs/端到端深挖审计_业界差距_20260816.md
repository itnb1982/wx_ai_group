### 五维差距清单

| 维度 | 业界做法 | 万象Ai 现状 | 差距 |
|---|---|---|---|
| **数据** | 新闻/宏观（利率/金价/油价）作协变量入环境；时序模型 fine-tune 到自有资产 | 仅 XAUUSD + SMC/CVD/Regime 多周期；Chronos-2 本地零样本未 fine-tune | 中——无新闻流、无协变量、无 fine-tune |
| **决策** | MM-DREX 让 VLM 输出实时专家权重并训练路由；FinAgent 反思+记忆持续适配 | 双脑辩论成熟；视觉仅"看图"不改权重；meta_agent 静态加权门控；全链路无训练/无记忆/无在线学习 | **大——静态裁决 vs 在线自适应** |
| **验证** | 滚动 walk-forward + 34 段 OOS 诚实披露；XAUUSD 实盘退化预算 10-20%；影子模式+10% 分仓 A/B 灰度 | 无 walk-forward/A-B/样本外框架，信号验证机制未系统化 | **大——最稀缺也最该补** |
| **执行** | slippage 建模（S=βσ√P）、TCA 事后归因、VWAP/TWAP 拆单、SOR 择路 | 错峰+幂等+镜像覆盖正确性；无 slippage 建模与执行质量度量 | 中——正确性已保，质量未量化 |
| **风控** | 事件硬停（CPI/NFP/FOMC 前 30min halt）、spread cliff、滑点/延迟超阈自动降载至零、可审计 kill switch+TCA 反馈 | 三层风控+人工通道；缺事件级硬停与量化触发降载 | 中——结构在，缺事件驱动维度 |

### 业界对 LLM 直出信号的共识批评

- 非校准概率、幻觉+置信度失真、训练数据与测试重叠致结构性过拟合、信号拥挤致 alpha 快速衰减（ChatGPT 策略 Sharpe 6.54→1.22）
- 主流缓解：LLM 只做因子/情绪提取而非直接下单 + 人机复核 + 多源交叉 + paper trading

## 第三部分：最值得借鉴的 3 个升级方向

1. **补验证层**（最优先）：滚动 walk-forward（含真实点差佣金）+ 影子模式 + 10% 分仓 A/B 灰度，性能退化即回滚——这是 LLM 交易系统当前最稀缺、也最能让信号可信的一步
2. **meta_agent 静态裁决→在线自适应**：引入 RL/增量学习（EWC 防遗忘）调权；VLM 识别 Regime→动态路由专家（MM-DREX 思路）；加反事实评测排除"记住行情"式假 alpha
3. **执行质量工程化**：slippage/延迟归因 TCA、超阈自动降载、重大事件前硬停（CPI/NFP/FOMC），补强现有三层风控
