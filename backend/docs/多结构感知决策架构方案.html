万象Ai · 多结构感知决策架构方案

目标：让 AI 大脑自主从 MT5 多周期趋势数据做多结构感知，据此产出正确的开单信号、仓位管理、平仓时机。<br>设计铁律（沿用）：提准非拦截——结构感知只作增强上下文（加法），绝不做成 GO/NO-GO 闸门；守住「交易笔数不腰斩 / 净利不降 / PF>1」及格线。
⚠️ 2026-08-13 实施修正（重要）：落地的第一步代码探查发现——本方案第三节设想的「新增 MarketStructureAnalyzer」与既有代码严重重复。系统早已实装并接入决策链的结构感知层：<br>- services/smc_features.py（OB/FVG/BOS/流动性扫荡/溢价折扣区，原 compute_smc）<br>- services/regime_detect.py（三周期体制/方向偏置/延伸度/末端风险，原 detect_regime）<br>- 二者由 core/market_analyzer.py 每周期计算并注入 snapshot.smc_features / snapshot.regime，且开单决策已消费：meta_agent.adjudicate 用 regime 调权 + SMC 订单流锚翻逆势单、LLM 提示词含 smc_features、trade_executor 用 global_bias 做平仓「不利结构」门控。<br><br>因此 Phase 1 不再新建重复模块，改为在既有 smc_features 上做结构锚定闭环（已落地，见下）：<br>1. smc_features.derive_structure_anchors()：从 H1/M15 摆动点推 sl_anchor（结构失效位）/ tp_anchor（下一结构目标），存 snapshot.structure_anchors（market_analyzer 注入）。<br>2. smart_exit.compute_initial_sl_tp()：消费结构锚——SL 挂在结构失效位（跌破=结构破=止损，不扛假突破），TP 延伸到下一结构目标；ATR 兜底 + MIN_SL_DIST 下限 + max_sl_atr_mult(默认6×ATR) 上限，无结构时零行为变化。<br>3. trade_executor 开仓调用处传入结构锚。<br><br>实测（合成 K 线）：结构锚推导正确、结构 SL 生效、ATR 兜底/方向校验/过远 clamp 全部按预期。剩余缺口见 Phase 2/3（仓位引擎消费结构止损距、平仓时机结构锚增强），均为加法非拦截。

一、核心洞察（来自你那两张 H4 图）

同样的"突破前高"形态：

  • 图1（趋势体制）= 真突破、延续 → 该跟。
  • 图2（震荡/派发体制）= 假突破、多头陷阱 → 该躲。

结论：大脑缺的不是"识别突破"的能力，而是识别这个突破发生在什么结构、什么体制里的能力。这正是多结构感知要补的环。

二、架构总览（七层闭环，见架构图）

  1. MT5 多周期数据接入 — H4/H1/M15/M5 的 OHLCV + 指标(MA/RSI/ATR/布林) + 量能；由 ts_reference_service 单例只读聚合，零额外开销。
  2. 结构感知层（双通道·加法增强） — 规则特征 + 视觉 VLM 双路融合。
  3. 体制感知 Regime — 趋势/震荡/派发 + 价格延伸度 Z-score。
  4. AI 大脑融合裁决（开单信号） — 方向投票 + 结构上下文 → 开单 + 校准置信。
  5. 仓位管理 — Chronos 风险区间 + ATR 止损距 + 结构位置 → 自适应手数。
  6. 平仓时机 — 结构失效 CHoCH + 流动性池 TP + 三层智能平仓。
  7. 闭环归因与在线进化 — brain_audit 按结构标签归因，反馈回感知/体制/决策。

三、结构感知层（最高杠杆，先落地）

新增 MarketStructureAnalyzer，每根 K 线收盘后跑一次（H4 低频，成本可忽略）：

3.1 规则特征通道（确定性、可回测）

  • 摆动点：swing high/low（N 根窗口），构成结构骨架。
  • BOS / CHoCH（ICT）：结构突破 / 特征转变，判定趋势方向切换点。
  • 订单块 Order Block / FVG 公允价值缺口：机构留下的足迹。
  • 流动性池 Liquidity Pool：相等高低点（Equal Highs/Lows），是 TP 的自然目标、也是扫损陷阱。
  • 价格延伸度：Z = (price - MA)/ATR，区分"健康贴均线" vs "趋势末端飞离"。
  • RSI 极值 + 量能背离：识别超买超卖与动能衰竭。
  • 输出 StructureContext：{regime, structure_type, location(突破/回踩/衰竭), liquidity_pools[], sl_anchor, tp_anchor, extension_z, rsi_extreme}。

3.2 视觉通道（VLM 直接读图，你 7·28 定的主路径）

  • 渲染 H4/H1 蜡烛图（叠加 MA/结构线/流动性池标注）为图片。
  • 视觉模型在独立模型服务内直接识别："这是趋势中的回踩买入，还是震荡区的假突破？"
  • 关键约束：视觉结论只作增强信号融合进方向投票提准确率，绝不做成闸门（拦截=砍交易=利润腰斩，等同旧铁律"提准非拦截"）。
  • 验证：历史图表渲染→视觉标注→与当前大脑对比回测，评判仍为净利/交易数/PF>1。

四、三个核心决策的改造点

4.1 开单信号（接 meta_agent.adjudicate）

  • 现有：deepseek + hunyuan + 融合票 + Chronos 出 final_decision / final_confidence。
  • 改造：StructureContext 作为上下文注入裁决——
  • 结构确认方向（趋势中回踩订单块 + CHoCH 向上）→ 置信提权（加法）。
  • 结构矛盾（震荡区突破进流动性池）→ 置信降权（非拦截，仅降权，守交易笔数）。
  • 复用现有 DebateDecision 结构，新增 structure_tag 字段，不破坏现有闸门。

4.2 仓位管理（接 Chronos + 手数引擎）

  • 现有：Chronos-2 出风险区间；手数引擎按风险%。
  • 改造：止损距离不再用固定 ATR 倍数，改用 StructureContext.sl_anchor（结构失效位，如跌破 swing low / CHoCH 翻转）算真实止损距 → 手数 = 风险金额 / 止损距。
  • 结构末端延伸(Z 大)时自动缩小手数（风险相同但距离远→单子小），避免"接飞刀"重仓。
  • CONFIDENCE_CALIBRATION_AFFECTS_SIZING 维持默认关，待 walk-forward 验证净盈利提升后再开。

4.3 平仓时机（接三层智能平仓 + 结构）

  • 现有 L1 SL/TP、L2 反向置信、L3 篮子锁利。
  • 改造：
  • SL 锚定结构失效位（sl_anchor），不是拍脑袋点数。
  • TP 锚定下一个流动性池（tp_anchor），吃机构扫流动性那段。
  • 趋势中：价格贴结构上行→移动 SL 到最近结构位追踪锁利（不提前离场，让利润奔跑）。
  • 震荡中：到流动性池即平，不贪突破。

五、闭环进化（接 brain_audit）

  • 每笔成交在 brain_audit 归因时带上 structure_tag + regime。
  • 统计"趋势体制下单" vs "震荡体制假突破单"的胜率/净利，让大脑知道自己在哪种结构挣钱、哪种亏钱，在线调整结构权重。
  • 这正是你定的"提准非拦截"的闭环验证：只加对净盈利有帮助的结构增强。

六、分阶段实施计划

  • Phase 1（地基·已落地 2026-08-13）：在既有 smc_features 上加 derive_structure_anchors + market_analyzer 注入 snapshot.structure_anchors + compute_initial_sl_tp 消费结构锚（SL 锚结构失效位/TP 锚结构目标，ATR 兜底零行为变化）。不新建重复模块。✅
  • Phase 2（开单增强）：StructureContext 注入 meta_agent.adjudicate 作提权/降权上下文（非闸门）；视觉 VLM 通道并行跑、只记录不干预。
  • Phase 3（仓位/平仓）：SL/TP 锚定结构位；手数按结构止损距；趋势追踪锁利。
  • Phase 4（闭环）：brain_audit 按结构标签归因，在线调权。

七、验收标准（不可妥协）

  • 交易笔数不腰斩、净利润不下降、PF 保持 >1（任一不满足即回退）。
  • 结构感知全程零闸门化：任何"拦截"改动须 walk-forward 验证净盈利提升。
  • 视觉通道延迟/成本可控（H4 低频，预算内）。
