## 三、业界差距对照（双源调研，2026 前沿）

### 本轮调研补充的关键共识（与我们的篮子方案同构）

| 业界做法 | 万象Ai 对应 | 差距 |
|---|---|---|
| **Safety-First：硬回撤/止损规则在 AI 逻辑之外**（"AI 是引擎，人是刹车"）| L1 硬 SL/TP + 篮子回吐保护（规则层兜底 AI）✅ | 已对齐 |
| **Drawdown control 是组合级**（portfolio level，不只单笔）| 篮子级 AI 持仓管理（position_action + 峰值回吐）✅ | 已对齐（用户哲学=业界结论）|
| **20/50 规则**：20% 回撤减半仓 / 50% 停止 | 无账号级回撤减仓（只有日亏熔断） | 中——可加账号回撤档位 |
| **Hybrid 最优**：人定规则、AI 执行、硬护栏兜底 | AI 建议 + 连续 2 轮防抖 + 置信门槛 + 规则护栏 ✅ | 已对齐 |
| **回测现实性**：fees/slippage/延迟纳入、walk-forward + OOS | 无系统 walk-forward 框架；辩论环 shadow 刚埋点 | **最大短板**（持续） |
| **信号校准**：Brier score <0.25、calibrated 不可妥协 | calibrated_confidence 已有 | 中 |
| **LLM 静默退化监控**：prompt drift / regime 变化再验证（每 90 天）| degraded 监控有；无 prompt 再验证节奏 | 中 |

### 上轮结论沿用（QuantInsti/P1GPT/TradingAgents/FLAG-Trader）
- **"LLM 当风控经理定仓位、不预测方向"**（QuantInsti 2026）= 用户"开完仓核心就是维护持仓"哲学，业界已验证
- P1GPT risk-aware exit / adaptive re-entry（回测 CR 16-32%、Sharpe 2.3-3.4）
- TradingAgents 回测 30.5% vs 实盘 7% 回撤 22%——回测≠实盘
- FLAG-Trader（ACL 2025）：LLM+RL 混合最优，我们缺 RL 层
