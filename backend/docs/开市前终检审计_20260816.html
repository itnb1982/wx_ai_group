二、本轮新发现并修复（6 项）

P0-2a【trade_executor.py:1888】rejected_signals fallback NameError 残留（复核补修）

  • 问题：ORM 路径已修，但原生 sqlite3 fallback 的 SQL 参数仍引用未定义的 entry_price/atr → NameError 被吞 → fallback 静默失败，表仍写不进
  • 修复：改用 _rs_entry/_rs_atr（与 ORM 路径同源）
  • 附带修复：_rs_saved = True 无条件赋值 → 改为按 _safe_db_write() 返回值赋值（写失败时正确走 fallback）

P1-3a【meta_agent.py:650-666】NaN/inf 置信经 clamp 变 1.0 满置信（复核补修）

  • 问题：float("nan") 合法，min(1.0, nan) 返回 1.0 → ds/hy_confidence 被 clamp 成 1.0 → 门控/手数全按满置信走，风控被击穿
  • 附带："1.5"（=150%）被 /100 误除成 0.015（权重消失）；"95%" float 抛错回退 0.5
  • 修复：_safe_conf() 统一处理——isfinite 判空回退 0.5、strip %、>100 才 /100、最终 clamp [0,1]
  • 验证：12 个边界用例全过（nan/inf/95%/150%/1.5/0.85/-5/None/空 等）

P2【trade_executor.py:2176】主号手数=0 仍可开（L3 熔断击穿）

  • 问题：主号路径无 position_size<=0 拦截（跟号已有），L3 熔断/降级把手数算成 0 后仍进 place_order 开 0.01 手假单
  • 修复：追价缩仓后加 if position_size <= 0: return（与跟号对称）

P1【trade_executor.py:3489】L2 反转平仓失败仍广播（主跟背离）

  • 问题：close_position 后无条件 publish_leader_exit——主号 close 瞬时失败仍广播 → 跟号平掉、主号保留 → 背离
  • 修复：成功/已不存在才广播；失败归还防抖状态待下轮重试（与 full_close 分支"失败绝不广播"对齐）

P1【smart_exit.py:406-414】HIGH 封顶回调 TP（利润提前落袋）

  • 问题：P90/P10 逐轮重算可下移，封顶钳位后 trailed_tp 可能 < current_tp（BUY）→ 判 != 即改单 → TP 被下调，违背"只上移不回调"
  • 修复：封顶后加方向护栏（BUY 低于 current_tp → None；SELL 高于 → None）

P1【trade_executor.py:3452】视觉 partial close_pct 越界 → 主平跟留

  • 问题：视觉 partial 的 close_pct 只 clamp [0,1]，≥0.95 时转全平但按 partial_close 广播；跟号镜像要求 [0.05,0.95] 越界忽略 → 主平跟留
  • 修复：≥0.95 改按 full_close 语义处理（与 partial 分支 vol_close>=vol_total 转全平一致）
